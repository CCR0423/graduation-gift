## 这是一片什么

这并非一次正式的工程交付，而是一件私人的毕业礼物。

它把「我们」装进一台会发光的网页：漆黑的底色上泛起金色的星尘，正中是一张九宫格，九格里，是我们中的九个。轻触任一名字，便翻入那一位独有的留白——一句藏着他名字的祝福，一张与他有关的照片，一段只对他一个人说的话。

首页有首页的旋律；走进每位朋友的页面，则共着一首相同的背景乐。它不为谁独奏，却替九个人守住了同一段可以溯回的当年。未拆之前，它是一张寄不出去的心意；拆开之后，每个人都能听见自己。

## 礼如何抵达你

这件礼物长在纸上，也长在掌心里。

临别之前，我们把每一个名字、每一句祝福，连同这座网页，一并写进一枚枚心意卡里——卡中安放着一枚 NFC 芯片，记着唯独属于那个人的地址。拿到卡片的人，手机不必输网址，只消轻轻一触，感应之间，页面便如一封早已写好的信，缓缓展开。

- **一张卡，一个网址，一人一份**：每张卡只指向那一位朋友的页面，各不相扰，如同各收各的信。
- **一册网页，安于云端**：网站寄存在 GitHub Pages 之上，免费而长久，不必谁守着电脑，随时回来，当年都在。
- **黑金之间，动静相宜**：首页 3×3 的黑金方格居中起柱，金色粒子缓缓升起；封面以「轻触开启」的仪式，温柔承接每一次相见。

## 若有些许不如意

礼物总愿尽善，偶有小事，也先说开，免得你暗自皱眉。

- **音乐偶尔卡顿**。背景音乐体量不小，云端分发线路又偶有起伏，边走边播难免磕绊。页面已在打开时就开始预先加载，等缓冲充足了再开声。若仍不顺畅，稍等片刻，或重新点一下角落的乐符，大多便好了。
- **无同步、无账密，也无推送**。这是一册只读的心意，不必登录，不收集任何信息，页面静静展开，读完即合——如同你我之间，本就没有那么多需要校验的东西。
- **关掉音乐，文字依然在**。浏览器或系统若暂时拦下自动播放，只消手动点一次乐符；那只是约定俗成的规矩，并不曾怠慢于你。
- **页面或会换新，心意常在**。日后若再更新，改的是几行代码，不改的是九格里站着的人。
